# Project Euler Solvers

[Project Euler](https://projecteuler.net) is a collection of various math/programming problems. Visit its site for more details. This repo is a collection of solvers for up to the first 100 problems (in accordance with PE's policy) implemented in Rust for my practice.

I will document the tl;dr of each problem and my thought process above each solver.

While performance won't be my first concern, I may provide multiple solvers when I attempt to come up with better solvers after having confirmed the answer.
